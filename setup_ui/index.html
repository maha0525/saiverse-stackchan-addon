Stack-chan ファーム書き込み

手順:
  1. Stack-chan の電源を入れて USB-C で PC に接続
  2. 「シリアルポートを選択」を押し、ポップアップから USB Serial Device を選ぶ
  3. 「書き込み開始」を押す (完了まで 30 秒〜1 分)
  4. 完了後、Stack-chan が自動再起動 → AP モード "Stack-chan-Setup" が起動
  5. スマホ等で AP に接続し、Wi-Fi 設定 + Vessel ID + Device Token を入力
※ Chrome / Edge 等 Web Serial 対応ブラウザが必要。Firefox / Safari は非対応。
このブラウザは Web Serial API に対応していません。Chrome または Edge をお使いください。
